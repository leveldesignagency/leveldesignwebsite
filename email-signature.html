Charles Morgan - email signature

Table-based HTML for Gmail. Open this page after deploy, select the signature block below, copy, then paste into Gmail Settings → See all settings → General → Signature.

How to add it in Gmail
1. Deploy this page (already on the site once pushed).
2. Open https://www.leveldesignagency.com/email-signature
3. Click inside the white preview box and select the black signature (Cmd+A inside the box, or drag-select).
4. Copy (Cmd+C).
5. Gmail → Settings → General → Signature → paste (Cmd+V) → Save changes.
6. Send yourself a test email and check desktop + mobile.
