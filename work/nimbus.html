Nimbus.

In-browser learning: highlight any text for definitions, AI explanations, translation, and pronunciation - without leaving the page you’re reading.

Type
Chrome extension
Deliverables
Product design, extension UI, brand
Live
Chrome Web Store

The idea

Reading online shouldn’t mean tab-hopping to dictionaries, translators, and search. Nimbus puts learning tools one highlight away - contextual, fast, and unobtrusive.

Design constraints

Extension UI has to work on any site, any theme, any font size. We built a compact panel system with clear hierarchy, readable type, and brand accents that don’t fight the host page.

How it works

  • Highlight to learn

    Select any word or phrase on a webpage - definitions and context appear instantly.

  • AI explanations

    Complex passages broken down in plain language - tuned for comprehension, not verbosity.

  • Translate & pronounce

    Hear correct pronunciation and translate on the fly - useful for language learners and researchers alike.
