Selected work

OnTimely.

A full event management platform and mobile app - designed front to back so organisers can run events from one place.

Sector
Event management
Deliverables
Brand, web app, mobile UI
Live
ontimely.co.uk

The challenge.

Event teams were juggling spreadsheets, messaging apps, and disconnected tools. OnTimely needed a single product that felt premium enough for professional organisers - and simple enough to use on the move.

What we built.

OnTimely lets companies create custom events and host them on a dedicated mobile app - with desktop tools for organisers, flexible homepage layouts for guests, and comms built in from day one.

Desktop dashboard.

Organisers run events from a full desktop command centre - a day-to-day dashboard for operations and an admin view for configuration, permissions, and oversight across every live event.

Homepage builder.

Customers build custom event homepages in a visual editor - shaping colours, sections, and layout so each event feels bespoke on mobile before guests download the app.

Create event.

Structured flows guide companies from event setup through publish - defining details, branding, and guest access so each custom event is ready to host on the mobile app.

Integrated chat.

A built-in chat system keeps companies connected with guests throughout the event - questions, updates, and announcements in one thread instead of scattered messaging apps.
